# 17: لوحة الخادم: حضور الجميع والتحليلات

**What to build:** الخادم يرى حضور كل المخدومين ونسبهم لكل نوع نشاط، ورسمًا بيانيًا لكل مخدوم على حدة، وعدد مرات التسجيل اليدوي لكل واحد، بنفس حساب النسب في صفحة المخدوم (ADR-001 وADR-004 وADR-007).

**Blocked by:**
- 16: صفحة "حضوري": النسب والرسم وآخر الجلسات
